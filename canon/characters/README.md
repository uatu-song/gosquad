# canon/characters — per-character topologies (the continuity spine)

One file per character, spanning every book they appear in. **A steward or cold
agent loads its character's file plus the embodiment file, and nothing else, for
continuity.** The whole-book topography (~17k words for Book 1) is the SOURCE
these are derived from, not something an agent should carry.

**Precedence for FACTS:** the shipped page > `DECISIONS_LOG` > the bible
(`TEMPORAL_MECHANICS.md`) > the book topography > `BOOK*_TOPOLOGY.yaml` >
profiles > embodiment. **The embodiment governs VOICE**, never facts. Where the
embodiment and the page disagree on a fact, the page wins and the file says so.

**Rules:** every fact traceable to a source; nothing invented; unresolved
questions marked UNRULED and listed at the end, never resolved by crew. Size:
**under 2,000 words per book per character.** Append a book section per book;
never rewrite an earlier book's ledger without a logged ruling. Template:
`_TEMPLATE.md`. Built 2026-09-02 for Book 1 (ARC 8d6417f) by crew, veto open.
