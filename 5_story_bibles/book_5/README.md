**Status:** Planning

## Overview

Book 5 is the TURNING POINT. CBT has definitively failed. The team must learn a new approach.

**Core Question:** How do you function when control is impossible?

## DBT Introduction

The shift from CBT to DBT happens here:

| CBT (Failed) | DBT (Learning) |
|--------------|----------------|
| Control outcomes | Accept reality |
| Fix problems | Tolerate distress |
| Evidence = truth | Act from values |

**Key Scenes:**
- A: Processing Book 4 losses + Jericho/Ben reveals → **Distress tolerance**
- B: Learning to function while broken → **Radical acceptance begins**
- C: Firas consciousness discovery → **Both/and**: Dead AND not dead
- D: First successful DBT-based action → Stalemate through acceptance, not control
