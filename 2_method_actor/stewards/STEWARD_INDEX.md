## Using Character Stewards

### For Scene Writing
1. Load relevant steward(s) for characters in scene
2. Check chapter-specific state
3. Validate against canon warnings
4. Use voice patterns for dialogue
5. Verify mode (Exploration vs Performance)

### For Arc Development
1. Reference emotional progression table
2. Track motives (stable vs evolving)
3. Verify knowledge gates (who knows what when)
4. Check relationships against other stewards

### Process Log Requirements
Each steward includes validation checklist. Before submitting prose:
- [ ] Load steward
- [ ] Check chapter state
- [ ] Validate canon warnings
- [ ] Run steward-specific checks
