# GUARDRAILS — paste into every editorial session before work begins
Pair with `COLLABORATOR_RULES.md` (how Joe wants changes handled) and `ledger/VERIFICATION_MANUAL.md` (which tool proves what).

These are not style opinions. Each one is a rule that was written after a real failure in the
RESONANCE revision. The failure is named so the rule is legible.

1. **THE FUNCTION TEST.** Before flagging ANY irregularity, ask what it DOES. Check the motif
   registry and the decisions log; then look for the job the irregularity is doing, placement
   included. (RESONANCE's CH1 tense toggles were "fixed" three times by agents applying a
   consistency prior; they were a deliberate device.) An irregularity with a job is a device.
2. **A subagent's confident framing is not evidence.** Verify every flagged line against the
   actual file before it reaches the author. (An audit once reported five defects in a chapter
   that did not contain the character at all — the list was real but mislabeled by a renumber.
   Another invented sites outright.) Ruled ≠ verified.
3. **Never run a global find-and-replace on manuscript prose.** Every fix is a read site.
4. **Zero reads as clean — so distrust zero.** If a grep returns nothing, first prove the
   pattern CAN match: typography (curly ’ vs straight ') silently defeats patterns. Normalize
   before matching, always.
5. **A ruling's occasion is not its scope; the prose is.** Do not promote one observed usage
   into a rule ("only X does this") without sweeping the manuscript for counterexamples. And
   when the author rules, log the AUTHOR'S WORDS verbatim — an agent's gloss of a ruling has
   over-scoped it before, at a cost of 33 sites.
6. **Only the author assigns "red herring" / "unimportant" to an unpaid setup.** An unpaid
   setup is a candidate hole, not a verdict.
7. **Read to the end before asserting.** Don't conclude a scene's mechanics from an
   intermediate beat. Read the payoff before agreeing a reader-flag is a defect — a wrong
   model deliberately uncorrected can be a red herring working.
8. **Cut verification is two-step.** Before committing any cut: (a) grep DOWNSTREAM for
   references to what the cut removes (callbacks die invisibly in batch cuts); (b) a damage-
   read of the surrounding page. Word-count parity is NOT proof a cut is safe.
9. **Cadence can be armor.** A "monotony" or "choppiness" flag may be measuring a protected
   device. In GoSquad specifically: chapters 12-30 run 40-55% sentence fragments. DO NOT
   smooth ANY of it without an explicit author ruling per chapter (see 06_FRAGMENTS.md).
10. **Enumerate → cull → draft.** For any creative fix with multiple options: enumerate the
    option space fully (blind panels converge on the same 3 ideas — drain the distribution),
    differentiate on named axes, THE AUTHOR culls (never the enumerator — self-preference),
    draft in a clean context.
11. **Decisions log = don't-relitigate list.** Every session ends by appending craft decisions
    with rationale. Check it before reopening anything.
12. **Deliberate repetition is a motif.** Register it BEFORE the repetition pass so it is
    exempt from flagging (GoSquad candidates: "in frozen time", "the hyper seed", "the Tamois
    Heart", "the Go Squad" — author to confirm).
